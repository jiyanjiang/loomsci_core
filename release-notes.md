## Project scanner

- `loomsci project scan --root <dir> --depth 3 --read-only`.
- Detects project roots from manifests, README, docs, scripts, and databases.
- Records paths, counts, README excerpts, DB files, and app port hints.
- Does not copy files or execute project code.
- Nested projects under a detected root are not auto-imported.

This release carries beta.7 login service, beta.6 DeepSeek settings, beta.5
runtime control, and the beta.2 Markdown post model.
