## 3. Gaps accepted into M1

These are implementation gaps, not architecture blockers:

1. Signing S10 copies only `payload.bin`; full Core package layout/rollback
   remains to be integrated.
2. Cert format is a prototype, not the final distribution format.
3. Installer does not install Core dependencies or a full hello-world package
   yet; it only provisions the runtime.
4. `uv` auto-download on a machine with neither uv nor a bundled uv is not
   tested; v0 assumes a bundled uv.
5. Backup prototype does not yet test app version mismatch or `--with-code`.
6. Migration apply is a prototype; production tool must stream/batch large
   project entries and expose the documented CLI.

Core = workspace + items + blobs + tags + search + app host + backup + updater

Migration = source read-only, new workspace, verify, then switch

## 5. Decision

**M0 conditional pass.**

Reason:

- All architecture-critical questions have written answers.
- Both platforms pass the process/runtime/signing/backup/migration prototypes.
- Remaining gaps are integration work in M1, not unresolved architecture.

Conditions before public distribution:

- full package install/rollback;
- final cert/trust format;
- uv bundled or auto-download strategy;
- migration tool batching and CLI;
- M1 Core acceptance tests.
